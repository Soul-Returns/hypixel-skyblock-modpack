Hypixel Skyblock Modpack

Minecraft 26.2 · Fabric · updates itself on every launch

  1. Install Prism Launcher and log in.
  2. Download Hypixel-Skyblock.zip from the releases page.
  3. In Prism: Add Instance → Import from zip, pick the file.
  4. Launch. The first start downloads the mods, so give it a minute.

After that, launching the instance is all an update takes. Your own mods and your own settings are never overwritten — see the README.

This page sits next to the pack metadata that Prism reads. The update URL is pack.toml in this directory — you do not need to open it yourself.
